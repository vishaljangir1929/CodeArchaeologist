# Start CodeArchaeologist

For a fresh GitHub clone, follow [Getting started](docs/GETTING_STARTED.md): install Python 3.12, run INSTALL.bat, run SETUP_AI.bat once, then run START.bat.

The original prepared local delivery already includes dependencies and models. In that copy, double-click START.bat.

The browser opens at http://127.0.0.1:8765. Keep the terminal open and press Ctrl+C when finished. Choose Legacy Shop for a first walkthrough.
